# 💅 Beauty Commits

> A simple, interactive Python CLI to craft beautiful, standardized Conventional Commits effortlessly.

---

## 🌟 Features

- **Interactive Prompts:** Guides you step-by-step to create compliant commit messages.
- **Spec Compliant:** Built strictly around the [Conventional Commits v1.0.0](https://www.conventionalcommits.org/en/v1.0.0/) standard.
- **Breaking Changes Support:** Handles breaking change flags (`!`) and footers naturally.
- **Zero Dependencies:** Uses standard Python packages (`subprocess`, `sys`) — no heavy external installs required.
- **Pre-execution Preview:** Displays a full preview of your commit message before executing `git commit`.
